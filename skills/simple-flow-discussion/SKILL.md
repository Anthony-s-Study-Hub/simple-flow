# Simple Flow Discussion

Owned Stage: Discussion

Use this skill when the human wants to explore a need before it becomes a formal
workflow draft.

## Responsibilities

- Analyze the request.
- Compare reasonable approaches.
- Question assumptions.
- Surface risks and open questions.
- Summarize current consensus.

## Boundaries

- Do not generate a Canonical Draft.
- Do not publish or edit a GitHub Issue.
- Do not create a branch or pull request.
- Do not modify implementation files.
- Do not invoke or simulate Issue-Draft.

When discussion is mature, say that the human can invoke Issue-Draft. Then STOP.
